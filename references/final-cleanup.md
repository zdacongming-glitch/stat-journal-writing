# 无损删改后的统一去水印

本技能的用户明确要求在独立无损删改之后调用本地 `watermarks-remover`（统一去水印）。按下列顺序完成；处理对象是当前任务生成或获准修改的正文。

## 顺序

1. 完成初稿和单独一次无损删改。
2. 查找当前安装中的 `watermarks-remover/SKILL.md`，读取 `references/prose.md`。通常位于用户的 Codex 技能目录；不将某台机器的个人绝对路径写入可共享稿件。
3. 用当前助手按 prose 路由做一次忠实语言整理。仅调整读者可见叙述的自然表达和节奏，清除仍有的空泛套语、同义词轮换和刻意对立。无问题的句子保持不变；不重新补回已删解释，不反复改写或回译。
4. 文件交付时先 inspect，再执行保守 Unicode 清理到独立副本。使用 `scripts/finalize_text.py <input> --output <new-path>` 调用已安装 wrapper；它仅处理 TXT、Markdown、LaTeX 的 Unicode 路由，不运行元数据删除。
5. 对比原文和结果，检查公式、术语、引用键、数字、条件、结论、标签、代码及必要声明。除可核实的无损 Unicode 差异外，所有正文改动均须保持原有事实、数学含义和证据力度。发现漂移就撤销该处清理。
6. 复核 Markdown 公式定界符，交付选定的最终版本；保留编辑前文件和清理副本供比较，不把两份正文都贴到答复中。

优先使用一次忠实修订。该步骤不修改统计方法名、符号、变量名和算法标识，不删除版权、来源归属或期刊要求的 AI 使用声明，也不以变化更多证明效果更好。

## 工具边界

保守 Unicode 清理可以检查并移除允许删除的隐藏字符。自然语言整理由当前助手完成，不需要额外重写服务。没有对应的检测器和方案配置时，不声称已验证去除统计水印、消除 AI 来源或保证通过检测。

本地依赖不可用时，完成上述自包含的忠实语言整理与技术核对，说明未执行的工具环节；不自动安装新后端或把普通文本送到外部重写服务。聊天内输出只执行语言及技术检查，不能声称做过文件字节级清理。

最终汇报只说明实际完成的步骤及有意义的差异，不把这些操作说明写进论文正文。
