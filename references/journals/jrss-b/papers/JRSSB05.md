# JRSSB05 — Gap statistic：把经验图形变成有参照的程序

Robert Tibshirani, Guenther Walther and Trevor Hastie (2001), *Estimating the number of clusters in a data set via the gap statistic*. JRSS-B 63(2), 411–423. [DOI](https://doi.org/10.1111/1467-9868.00293)。原创方法论文。[所读期刊扫描全文：作者网站](https://hastie.su.domains/Papers/gap.pdf)。全文经本地英文 OCR 后读取；主文 §§1–8、PDF pp.1–11，证明附录未逐行验算。OCR公式不作为独立数学验证依据。

## 入选与摘要

Crossref 期刊查询（2026-10-19）记录 5037 次引用；其将 elbow 图形、无簇参照和可实施选择准则连接的思想提供实质入选理由。摘要依次给任务、兼容已有聚类算法的机制、理论和模拟，不详列所有比较方法。

## 引言推进

§1 首段从 elbow 图说明现有启发式尚缺哪一步统计解释；第二段用综述定位既有方法；第三段说明方法适用面与理论分析采用的 K-means 情境（p.411）。引言很短，完整定义直接进入 §2，没有额外重复贡献清单。

## 理论、计算与证据

§2 由簇内离散度构造相对参照的 gap；§3 的两个理论结果分别解释一维参照为何合理、多维中为何不存在通用非退化参照。负面结果导向 §4 的主成分取向盒形参照，而不是独立展示数学困难（pp.412–415）。计算规则随即给出，然后以两簇和无簇图检查行为。微阵列例子显示多尺度局部峰；之后 §5 才集中介绍比较方法，§§6–7 分别检查清楚分离与重叠情形（pp.415–420）。

## 结尾、可迁移动作与例外

§8 要求查看整条曲线，再讨论其他参照和只有相异度的情形（pp.419–421）。可迁移：让图形直觉、目标量、理论限制、可行近似和数值检查依次依赖；负面定理应改变实际方法选择。例外：不能将无簇检验、分布分量数和所有应用中的“真实簇数”混为一谈；本文主动承认 cluster 的定义依情境而变。也不能由这一篇短引言规定 JRSS-B 一律缩短引言。
