# JRSSB11 — Sure independence screening

Fan, J. and Lv, J. (2008). *Sure independence screening for ultrahigh dimensional feature space*. JRSS-B 70(5), 849–911. DOI: [10.1111/j.1467-9868.2008.00674.x](https://doi.org/10.1111/j.1467-9868.2008.00674.x)。讨论论文，讨论不另计核心篇数。

来源：[作者 arXiv 稿](https://arxiv.org/pdf/math/0612857)，v2，2008-08-27，43页。2026-10-19完整阅读主文 §§1–6，PDF pp.1–29；附录证明未逐行核验。页码以下均为该作者稿 PDF 页码。

入选依据：Crossref 2026-10-19 引用计数2117；筛选后选择的两阶段结构和 sure screening 概念形成持续研究方向，补充核心库中的超高维建模。

## 叙述推进

摘要先给计算与统计难题，再定义筛选所保留的性质、说明第二阶段和迭代扩展。引言 §1.1（pp.2–3）从线性模型与应用进入，肯定已有选择方法，再列高维计算、误差界、条件验证和模型恢复四个障碍。§1.2把目标缩小到快速降至样本量以下，并区分保留真变量、估计风险和最终选择；§1.3用伪相关、共线性、信号和尾部解释困难。这里的长文献段落服务于两阶段定位，不是要求所有文章写长综述。

§2（pp.6–9）先给最简单的边际相关排序及保留规则，然后用迭代阈值岭回归 ITRRS 解释构造与证明思路，最后连接二分类中的两样本统计量。名称中的 independence 指逐个拟合，不是协变量必须互相独立。ITRRS 是分析桥梁；它与后文基于残差的 ISIS 作用不同。

§3（pp.10–18）将成熟的中等维选择器装入第二阶段，再比较筛选覆盖、最终模型大小、估计误差及计算可行性。白血病分类例子是方法演示，训练与测试样本分开；不能把较少分类错误写成新的基因机制发现。§4（pp.18–24）先明确边际无关但联合相关、噪声相关较高和共线性三种失败，再提出残差迭代，并为这些失败模式专设模拟。新方法的困难直接决定数值设计。

§5（pp.24–28）集中列条件和定理，解释各条件控制的信号、协方差及维度增长，再把筛选性质接到第二阶段风险和 oracle 性质。§5.3明确为避免预筛选偏差可以样本分割。§6（pp.28–29）总结已证的 SIS/ITRRS，随后将 ISIS 的有限样本改进与尚未证明的放宽条件区分；提出广义损失、固定设计和非参数扩展的具体问题。

## 可迁移动作与边界

- 对流水线贡献，分别说明各阶段目标和交接条件，不能把保留真变量等同于精确支持恢复（§§1.2、2.1、5）。
- 方法有清楚失败模式时，让扩展和模拟逐一回应它们（§4）；若论文没有这种结构，不必强行制造失败清单。
- 数值先于集中理论可以成立：先让读者理解算法和作用，再给完整渐近依据（§§3–5）。
- 理论与实践进展分别落句。文中 ISIS 表现良好不意味着本文已经证明 ISIS 在更弱条件下 sure screening（§6）。
- 长篇技术假设解释、阶段二方法回顾和多个开放问题与本篇框架型讨论论文相适应，不机械移植到紧凑的单一方法文章。
