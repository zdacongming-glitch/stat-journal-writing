# JASA：从问题、统计任务到可采用的证据

本指南依据[25篇核心论文](core-corpus.json)的实际全文主体阅读形成，核验日期为2026-10-19。逐篇卡记录读取版本、章节或页码、叙述分析和不可泛化之处。这里的“规范”是写作判断依据；它们不替代投稿时最新作者要求，也不构成接收保证。

## 证据范围与使用次序

核心题录的`citation_evidence.annual_snapshot`保存OpenAlex来源、检索日和可见逐年引用窗口。25篇在2021–2025各年均仍有引用，作为持续影响的辅助证据；该窗口不等于完整引用史或领域共识排名。

核心库从2000年至今候选中选择，实际覆盖2001–2018年，兼顾方法、理论、算法、调查抽样、金融、环境、生物和社会应用。选篇使用OpenAlex当日高引候选、论文中的原始贡献和方向覆盖；经典性及获取偏差见[筛选说明](selection-audit.md)。另以正式发表于2021和2023的[两篇文章](calibration-corpus.json)校准叙述逻辑与术语，实际读取版本均为2020年作者稿。不能据此宣称唯一“最经典前25”、已查遍后续综述、已核对近期终稿版面或2026年的全部实践。

25篇均取得完整PDF，已阅读摘要、引言和全部主体叙述、方法与理论的衔接、数值或应用及结尾。证明附录和补充实验是否阅读逐卡说明；这不是独立数学审计。部分材料为作者稿：HDP为2005稿，空间极值为2005稿，TBATS为2010稿；森林、PELT、CLIME及Pólya–Gamma也采用有版本标识的作者稿。引用其篇章位置时使用卡中页码，不替换成未经核对的出版社页码。

调用时先确定“JASA × 研究方向 × 文章类型”，再读相关卡。以下跨方向观察只能作为初始判断；某方向的正式profile须另外真实读满至少10篇该方向目标期刊论文，并按主流程保存增量证据。本库没有以宽泛主题拼凑一个满10篇的方向profile。

## 先确定文章要交付什么

Theory and Methods通常需要读者明白统计任务、已有方案的具体障碍、新构造如何解除障碍，以及保证和证据的范围。Applications and Case Studies通常还需要明确科学对象、观察及记录机制、比较基准和结果的实质含义。两类都可以包含新方法与理论；不能按是否出现真实数据机械分类。

| 可执行判断 | 支持位置 | 适用条件及反例 |
| --- | --- | --- |
| 引言让读者知道现有实践在哪一步失效，再提出所需变化。 | [JASA01](papers/JASA01.md) §1、pp.1348–1350；[JASA02](papers/JASA02.md) §§1–2、pp.1418–1420；[JASA09](papers/JASA09.md) §§1–2 | 适合修正已有估计器或算法。没有真实失败机制时不要虚构“不足”。 |
| 可以直接以形式化目标开篇。 | [JASA21](papers/JASA21.md) §1、作者稿pp.3–6；[JASA05](papers/JASA05.md) §1、pp.1167–1168 | 目标本身已经解释问题时适用；无需先写宏观重要性段落。 |
| 复杂应用先给最终使用量，再解释模型参数。 | [JASA24](papers/JASA24.md) §1、作者稿pp.2–9；[JASA23](papers/JASA23.md) §§1–3、pp.813–817 | return level、条件盘查率等实质目标需要先辨明。背景长短由识别与数据解释需要决定。 |
| 多项贡献必须共同回答一个问题。 | [JASA22](papers/JASA22.md) §§1、3–7、pp.36–49；[JASA25](papers/JASA25.md) §§1–4、作者稿pp.4–33 | 多个原始过程或多种季节性可以组织全文。不要强行改成一个估计器加一个定理的结构。 |

环境抽样的[GRTS](papers/JASA15.md)正式属于Theory and Methods，其引言却由现场约束推进；HDP的[长构造稿](papers/JASA04.md)与Bayesian lasso的[短方法稿](papers/JASA06.md)也采用不同篇幅。栏目不是固定章节模板。

## 引言按信息依赖推进

为每个引言段落标一个实际功能：确定目标、展示障碍、比较最近方法、解释新动作或交代证据。没有功能，或与相邻段落重复同一功能而无新事实，就删去或合并。不要为“领域重要性—现状—缺口—贡献—结构”填满固定段数。

几种经全文支持的推进方式是：

- 设计准则先于构造：非凹惩罚以无偏、稀疏和连续性组织选择理由，而不是先列方法名。[JASA01](papers/JASA01.md)，§§1–2。
- 失败条件先于修正：adaptive lasso先说明普通lasso的选择问题，再引入数据依赖权重。[JASA02](papers/JASA02.md)，§§1–2。
- 科学例子建立需求，再逐例返回：TBATS用非整数、多重和双日历三个例子定义需求，结果部分保持对应。[JASA25](papers/JASA25.md)，§§1、4。
- 诊断现象引出估计对象：经验零分布通过大规模检验的实际分布形状定位问题。[JASA18](papers/JASA18.md)，§§1–3、pp.96–99。
- 最终任务先出现，通用理论随后支撑：causal forest先定义目标及算法，再建立回归森林工具并返回因果定理。[JASA07](papers/JASA07.md)，§§2–4、作者稿pp.5–19。

相关工作比较到“解决哪一步、需什么条件、提供哪种保证”。HDP把相关先验放到共享参数的问题上；conformal把预测覆盖与系数推断分开。[JASA04](papers/JASA04.md)，§§1–3；[JASA21](papers/JASA21.md)，§1。不要只按作者或年份排列文献，也不要为一个有限改进虚构整个领域都失败。

## 方法与理论沿同一条依赖链展开

| 需要的写作动作 | 证据 | 保留的区别 |
| --- | --- | --- |
| 定义估计对象后，再定义计算对象和算法。 | [JASA16](papers/JASA16.md) §§3–5、pp.1079–1084；[JASA11](papers/JASA11.md) §§2–3、pp.1091–1094 | 随机块标签交换先决定哪些量可识别；latent-space旋转不识别也影响展示。不能等算法结束才解释估计量含义。 |
| 构造多个等价表示时，逐一说明它们为哪项任务服务。 | [JASA04](papers/JASA04.md) §§3–6；[JASA14](papers/JASA14.md) §§3–5、pp.164–169 | 概率定义、预测规则、后验抽样不必重复同一段动机。新表示不是自动增加一项独立贡献。 |
| 按均值、协方差、特征分量、条件预测的依赖组织方法和理论。 | [JASA13](papers/JASA13.md) §§2–3、pp.578–583 | 稀疏个体轨迹的条件预测与真实轨迹的一致恢复不同。 |
| 将估计误差、支持恢复及风险目标分开说明。 | [JASA19](papers/JASA19.md) §§2–4、作者稿pp.5–20；[JASA17](papers/JASA17.md) §§2–4、pp.140–151 | CLIME高概率界、修正后的期望风险及阈值支持恢复并非同一命题；surrogate误差、估计误差和逼近误差也不同。 |
| 让算法正确性和运行效率各有证据。 | [JASA09](papers/JASA09.md) §§2–3；[JASA20](papers/JASA20.md) §§3–5、作者稿pp.6–21 | 精确最优分段不等于所有情形线性耗时；接受率高不等于任意形状参数抽样都快。 |

关键证明可以保留正文：分类风险变换及快速速率的解释性证明本身推进论证；森林正文也详细说明Hájek投影和incrementality。其他稿件把证明放附录，让正文维持方法与证据的推进。[JASA17](papers/JASA17.md)，§§2–4；[JASA07](papers/JASA07.md)，§3；[JASA05](papers/JASA05.md)，§§2–3及附录。不能把“所有证明移附录”定为JASA统一风格。

定理之后只写读者当前需要的后果、关键条件的作用或与最近结果的差异。已清楚引用假设组时，不逐句重述全部条件；也不为每个定理固定添加直觉、范围、实践、局限四个段落。保留足以阻止误读的区别，例如conformal的边际覆盖与条件覆盖，但将它放在覆盖声明附近。[JASA21](papers/JASA21.md)，Remarks 2.3、2.5，作者稿p.9。

## 数值与应用回答可区分的问题

模拟先列需要检查的主张，再设置能隔离该主张的因素。causal forest分开检验混杂调整、效应异质性和尖峰偏差；PACE改变观测密度与得分分布；分类理论改变曲率并检查速率斜率。[JASA07](papers/JASA07.md)，§5；[JASA13](papers/JASA13.md)，§4；[JASA17](papers/JASA17.md)，§4.3。每张表图必须改变读者对某一主张的判断。

比较保留对手表现好的条件。自适应惩罚的比较随信号噪声而变，blocked Gibbs不在每种先验下都胜过加速Pólya urn，Pólya–Gamma也明确区分ESS和每秒ESS；conformal在低维正确参数模型下允许经典区间更短。[JASA02](papers/JASA02.md)，§4；[JASA14](papers/JASA14.md)，§6；[JASA20](papers/JASA20.md)，§5；[JASA21](papers/JASA21.md)，§4。不要用“全面优越”覆盖这些结果。

应用须说明进入分析的数据是如何形成的。肿瘤分类解释标准化、特征选择与误差估计；微阵列empirical Bayes把实际实验和零分布估计连接；实现波动说明采样、插值及假日剔除；呼叫中心追溯异常短通话和运营变更。[JASA08](papers/JASA08.md)，§§2–4；[JASA12](papers/JASA12.md)，§§2–5；[JASA10](papers/JASA10.md)，§3；[JASA22](papers/JASA22.md)，§§2、4.1。记录机制会影响推断时，这些细节不是可以删去的背景。

结论回到实质目标，而不只解释统计量：synthetic control返回政策效应及placebo比较，空间极值返回地图和区间，社会网络返回结构解释；盘查研究区分条件差异、行为机制和公平判断。[JASA03](papers/JASA03.md)，§§3–4；[JASA24](papers/JASA24.md)，§§4–5；[JASA11](papers/JASA11.md)，§4；[JASA23](papers/JASA23.md)，§§5–6。

## 近年发表论文提供的校准

[JASA-C01](papers/JASA-C01.md)（Chatterjee，正式2021）以三项需要满足的性质组织问题，定义后说明已知总体目标与新估计式的关系，再区分关系度量、独立性检验、计算代价和power。这支持“贡献定位到新动作”和“不同评价目标分开”，也提醒我们：有实质比较对象的转折和防止误解的Remarks应保留。证据位置为2020作者稿§§1–4、7–8，pp.1–14、19–21。

[JASA-C02](papers/JASA-C02.md)（Ren、Wei与Candès，正式2023）从随机种子导致选择集变化的实际障碍进入，把算法、一般保证、附加条件下精化及相关诊断相连接；多阶段GWAS始终追问筛选后是否仍在检验原有条件假设。这支持“每个算法改动重新核对随机性和目标”，而不是按新旧文体推定可以删掉范围说明。证据位置为2020作者稿§§2–6，pp.2–20。

两个校准样本均属于Theory and Methods，不代表近年ACS，也不证明期刊存在统一的新写法。它们与25篇核心数分开；NSF公开终稿链接获取失败，实际采用完整作者稿，故校准范围限于叙述与术语，不含未经核对的最终章节长度和版式。

## 术语保持文献含义

起草前把关键术语和最邻近方法登记到术语表，逐一核对原始定义、后续常用称呼和本稿差异。同一名称只对应同一个对象；已有通行术语不另造近义名。需要新名时先记录检索结果和定义差异。

| 易误用的名称 | 应核对的含义及原文位置 |
| --- | --- |
| oracle property | 指定的渐近序列、选择和估计性质；不是无条件有限样本最佳。[JASA01](papers/JASA01.md) §3；[JASA02](papers/JASA02.md) §§2–3。 |
| local false discovery rate、empirical null | 局部后验式量与尾部FDR不同，零分布的估计也有特定模型及应用条件。[JASA12](papers/JASA12.md) §§2–3；[JASA18](papers/JASA18.md) §§2–5。 |
| realized volatility、integrated volatility | 实现量、二次变差、扩散下的积分量和期初条件方差有不同含义。[JASA10](papers/JASA10.md) §2。 |
| classification calibration | 总体条件风险的符号校准；不等同于凸性或有限样本拟合良好。[JASA17](papers/JASA17.md) Definitions 1–2、Theorems 1–2。 |
| honesty、causal forest | 本文定义的样本使用限制及满足条件的森林；不泛指所有随机森林。[JASA07](papers/JASA07.md) §2.4、Definitions 2/2b。 |
| distribution-free prediction、LOCO | 有效性所需的数据假设、边际预测对象，以及全局LOCO条件于训练划分的目标需分别写清。[JASA21](papers/JASA21.md) §§2、6。 |

这些是本库支持的核对例子，不是免检词典。后续方向学习仍须查该方向的原始文献和目标期刊用法。

## 最后两次独立检查

先做无损删改。对每一句拟删除内容，检查是否会丢失事实、必要推理、明确指代或结论成立范围；无损则删除，重复则合并。删去套话、先行解释下一段将做什么、已经清楚的条件复述和无证据的意义扩张。长定义、测量说明、识别限制有实际任务时保留。

再执行主skill规定的“统一去水印”文本整理，并核对术语、引用、数字、公式、条件和结论强度。不得把必要对比统一改为直陈，也不得为了平滑叙述淡化不确定性。最后检查段落之间是否真的存在因果、递进或对象承接；确有比较、权衡或需要纠正的相关预期时才使用相应转折表达。

摘要按本稿主线选择任务、方法、最重要结果和证据，不强行塞入全部扩展。讨论解决结果意味着什么、尚未处理的具体障碍或采用方法所需条件。Bayesian lasso、stick-breaking和呼叫中心的结尾长度与形式不同，说明无需统一成贡献复述加三条future work。[JASA06](papers/JASA06.md)，§5；[JASA14](papers/JASA14.md)，§6末；[JASA22](papers/JASA22.md)，§7。
